# The Generative Turn in Search and Recommendation

Static workshop website for a research workshop on generative search and recommendation.

## Edit Content

High-change workshop details are marked in `index.html` with `EDIT:` comments. Replace the visible `TBA` fields when the room/location, invited speakers, schedule details, and contact email are finalized.

## Publish On GitHub Pages

1. Push this repository to GitHub.
2. Open repository settings.
3. Under Pages, choose deployment from the root of the main branch.
4. Save. The site will be served as a static GitHub Pages site.

No build step or package install is required.
